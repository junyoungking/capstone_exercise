# 중간 발표 산출물 (2026-10-22)

- `pipeline.png`, `pipeline.svg`: 전체 파이프라인 구조도.
- `squat_compare_demo.html`: 두 영상 업로드 → 처리 → 비교 리포트 데모 페이지. 화면 녹화용이다.
  - 한 파일로 돈다 (분석 결과, three.js, 글꼴이 안에 들어 있다. 인터넷 없이 열림).
  - 정해 둔 영상 두 개에만 맞는다: 내 영상 `stu10_70.mp4`(team9), 기준 영상 `test_squat_web.mp4`(공개 표본 `test_squat.mov`를 원래 fps의 H.264 CFR로 바꾼 것). 칸을 바꿔 넣으면 길이로 알아보고 바로잡는다.
  - 실제 값: 횟수, rep 시각, 깊이, 속도, 속도 저하, 템포, 바 경로, 템포 비교 문장 (plate-pipeline 출력).
  - 목업: 처리 화면(시간만 흐름), 종목 인식 97%, 관절 각도 표·3D 자세(실제 바 깊이로 움직이는 모형), 상체 기울기 문장과 무릎 각도 값. 골격 그림은 실제 포즈를 rep 진행별로 모은 중앙값이다.
- `src/`: 만들 때 쓴 스크립트 (`prep.py` → `skel.py` → `build.py`, 구조도는 `diagram_make.py`). 경로는 작업 세션 기준이라 그대로는 안 돈다.
