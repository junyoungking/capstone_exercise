# 중간 발표 산출물 (2026-10-22)

## 그림
- `pipeline.png`, `pipeline.svg`: 전체 파이프라인 구조도.
- `angle_correction.png`: 카메라 각도 보정 실험. 실제 바 경로(stu10_70, 5 rep)를 가상 카메라 각도로 다시 투영해 깊이 오차를 비교했다 (`src/angle_sim.py`, 결과 `src/angle_sim_result.json`).
  - 원판 크기 하나로 환산하면 60°에서 34% 오차가 난다.
  - 가로·세로를 따로 환산하는 지금 방식은 옆으로만 돌렸을 때 0.7%, 위에서 20° 내려다보면 6%다.
  - 원판 타원을 원으로 펴는 방식(추가 예정)은 모든 조건에서 1.1% 이하다.
- `alignment.png`: 템포가 다른 두 영상을 바 높이 비율로 정렬하는 방법 (실제 rep 1끼리).
- `rep_vs_set.png`: rep 단위와 세트 단위 판정의 근거. 포즈 무릎각은 rep마다 ±9° 흔들리고, 원판 깊이는 ±0.6 cm다.

## 데모 페이지
- `squat_compare_demo_v2.html` (현재): 운동 기록 → 새 비교(업로드) → 처리 → 비교 리포트. 한 파일이라 인터넷 없이 열린다.
  - 내 영상: `squat_user_set.mp4`. squat_02~05를 24 fps H.264로 이어 붙인 파일이고, 6 rep이다. 영상은 저장소에 없다.
  - 기준 영상: `stu10_70.mp4` (team9).
  - 실제 값:
    - 원판 파이프라인: 횟수, rep 시각, 깊이, 속도, 템포. 템포 비교 문장은 k·SE 판정 결과다.
    - MediaPipe (매 프레임): 2D 골격과 3D 관절(world landmarks를 다듬고 원판으로 크기를 맞춤).
    - 3D 관절로 계산: 자세 각도와 자세 문장. 세트 단위로 |차이| > 3·SE이고 최소 변화를 넘어야 문장이 된다.
    - 원판 크기로 계산: 카메라 각도, 거리·키·분절 길이. 거리·키·분절 길이는 폰 화각을 가정한 추정이다.
    - 진행 바 북마크와 세트 안에서 튀는 rep.
  - 목업: 처리 화면(시간만 흐름), 종목 인식 97%, 지난 날짜의 기록(예시).
  - 원판을 잡을 때 squat_03과 squat_04는 첫 프레임에 앞쪽 원판 상자를 손으로 지정했다. 검출기만 쓰면 반대편 원판을 잡거나 바닥에서 흔들렸다.
- `squat_compare_demo.html`: 첫 버전 (stu10_70 대 공개 표본).
- `src/`: 만든 스크립트 (`prep3.py` 번들, `pose_all.py` 포즈, `template2.html` 페이지, `figs.py` 그림). 경로는 작업 세션 기준이다.
