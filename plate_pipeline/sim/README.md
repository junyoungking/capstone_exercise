# Mc 완료 시각 보정 검증

`python eval/mc/sim.py`는 `sim.gen`의 같은 난수 시드로 만든 360개 세트에
완료 시각 보정을 끄고 켜서 각각 평가한다. 스쿼트·벤치·데드, 15/30/60 fps,
위치 잡음 표준편차 0.003/0.01/0.02/0.03/0.04 m와 조건당 8개 시드를
사용한다. 상태기계의 진입·최소 이동·복귀 임계값은 변경하지 않았다.
결과와 조건별 시드는 `results/mc/sim.json`에 있다.

| 항목 | 끔 | 켬 |
|---|---:|---:|
| 정확한 세트 횟수 | 359/360 | 359/360 |
| 극점 조건 통과 | 359/360 | 359/360 |
| 이벤트 TP / FP / FN | 1545 / 365 / 526 | 1603 / 372 / 468 |
| 이벤트 정밀도 | 80.89% | 81.16% |
| 속도 MAE (m/s) | 0.04256 | 0.04250 |

기존에 이벤트가 완전히 일치하던 세트에서 새 오차는 생기지 않았지만,
이미 불일치하던 일부 세트에서는 FP가 늘었다. 합성 신호의 전체 정밀도
상승이 모든 촬영 조건에서 정밀도를 보장하지는 않는다.

## M5 원판 선택 기본값

M5에서 `python eval/m5/sim.py`로 동일한 360개 신호를 다시 평가했다.
상태기계와 속도 설정은 변경하지 않았으며 `results/m5/sim.json`의 전 조건
결과는 기존 `results/mc/sim.json`과 동일하다. 이 신호 합성은 원판 검출과
리프터 선택을 모사하지 않으므로 그 부분은 별도의 실제 영상 평가를 쓴다.
